A responsive personal portfolio website introducing me, my background as

This project was built as part of the **Complete Web Development

## About the Project

The website is a simple personal introduction and portfolio landing
page. It includes:

-   **Hero section:** My name and current professional focus.
-   **Profile section:** A short introduction.
-   **About Me section:** My experience as a German teacher and my
    transition into web development.
-   **Contact section:** Direct contact link.
-   **Footer:** Social and professional profile links.

## Built With

-   HTML5
-   CSS3
-   CSS Grid
-   Flexbox
-   Responsive design with media queries
-   Google Fonts (Caveat and Roboto)

## What I Practised

While building and customizing this project, I practised:

-   Structuring a multi-section webpage with semantic HTML.
-   Styling layouts with CSS Flexbox and Grid.
-   Working with background images, typography, spacing, and alignment.
-   Making a layout responsive for smaller screens using media queries.
-   Using links for email contact and external profiles.
-   Organizing project files and assets.
